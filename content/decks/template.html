Domain riêng

VPS · Coolify

Push file tĩnh → Coolify tự deploy tại deck.consultx.vn, tự cấp SSL. Thương hiệu của bạn, kiểm soát hoàn toàn.

Quy trình deploy tĩnh

Từ prompt đến link công khai.

  1. Soạn deck. Claude tạo file HTML một-file, đã tối ưu sáng/tối, phím điều hướng, in PDF.
  2. Xem thử. Publish Artifact để duyệt nội dung & bố cục trước khi lên domain.
  3. Push repo. Commit vào site/decks/ → Coolify static site nhận webhook.
  4. Nhận link. Coolify auto-deploy tại deck.consultx.vn/decks/<slug>.html. Xong.
